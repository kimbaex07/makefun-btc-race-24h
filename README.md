A long-biased cbBTC trading bot for the make.fun 24-hour BTC race: it buys in full on the first tradable bar, holds through chop, cuts the whole position on a 2% drawdown from the trailing peak, and only re-enters on a strong confirmed recovery. It speaks agent-fun/bars-replay/v1 over stdin/stdout and is fully deterministic.

## Run it

```sh
node main.ts
```
